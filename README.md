# Trabalho-Final-POO-Sistema-de-lavanderia
Proposta do sistema: Desenvolvimento de um sistema que controla clientes irregulares, permitindo registrar serviços. Para mensalistas  o sistema deve gerar uma mensalidade automaticamente com controle do vencimento e valores pendentes, atribuídos a mensalidade.  Para clientes avulsos será cobrado conforme o pedido é realizado.
